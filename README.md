# 유빈의 원리책 — 위험물산업기사

암기가 아니라 원리로 공부하기 위한 학습 페이지. GitHub Pages로 배포합니다.

- `index.html` — 앱 (원리책 · 원리 분류 연습 · 진로 지도 · 내 기록)
- `data-principles.js` — 원리책 데이터 (14단원 69원리, 에듀윌 2026 교재 목차 기준)
- `data-quiz.js` — 기출 유형 문항 92개 (원리 분류 연습 · 단원 통과 시험 공용)

학습 흐름: 단원의 원리를 모두 "설명할 수 있음"으로 체크 → 단원 통과 시험 80% 이상 → 다음 단원 개방. 진도·메모는 브라우저 localStorage(`yubin.v2`)에 저장.

배포: Settings → Pages → Branch `main` / `(root)` → https://syrccm.github.io/yubin/
